# 0003 — Private Project Tracking

**Status:** Accepted

## Context

Public Issues and Discussions are disabled, but execution still needs a
private operational view.

## Decision

Use a private GitHub Organization Project with private draft items for execution
tracking and the Parking Lot.

## Consequences

Tracking flow, fields, and statuses are authoritative in [GitHub Infrastructure](../infrastructure/GITHUB.md).

## Reversal condition

Enabling public trackers or replacing the private Project requires explicit
owner approval because it changes repository governance and tooling.
