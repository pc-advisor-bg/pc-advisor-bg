# 0002 — Public Source, Rights Reserved

**Status:** Accepted

## Context

The V1 repository is intended to be publicly viewable without creating an
open-source contribution or licensing commitment.

## Decision

Keep the repository public source with all rights reserved; grant no
open-source license and accept no external contributions for V1.

## Consequences

The public-source and contribution policy is authoritative in [GitHub Infrastructure](../infrastructure/GITHUB.md).

## Reversal condition

Any change to licensing, repository visibility, or contribution policy requires
explicit owner approval as a legal or repository-governance decision.
