# 0001 — Cloudflare Hosting

**Status:** Accepted

## Context

PC Advisor BG needs an approved hosting platform while keeping Staging and
Production separate.

## Decision

Use Cloudflare as the hosting platform.

## Consequences

Hosting choices and environment boundaries follow [Cloudflare Infrastructure](../infrastructure/CLOUDFLARE.md); this record authorizes no provider action.

## Reversal condition

A different hosting provider requires explicit owner approval as an
architecture-affecting provider change.
